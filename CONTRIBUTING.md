# Contributing

This is a private-first fork of [MrDeathFox/fox-aternos-bot](https://github.com/MrDeathFox/fox-aternos-bot).

1. Open a GitHub Issue before substantive features/fixes when working on `heavygee/camofox-aternos`.
2. Branch from `main` (`feat/…`, `fix/…`).
3. Run `npm test` before opening a PR.
4. Never commit `.env`, profile dirs, or storage-state cookies.
5. Do not add ad-skipping (DOM removal, resource abort of ads, or process killing).

Upstream PRs target `MrDeathFox/fox-aternos-bot` from the public fork `heavygee/fox-aternos-bot`.
